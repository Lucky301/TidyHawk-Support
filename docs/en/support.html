Frequently asked questions

How do I get started?
  1. Choose Quick Scan or a cleanup category.
  2. Allow access to the folder shown in the folder picker. Scanning does not delete files.
  3. Review names, paths, and sizes, then select only the items you want.
  4. Check the confirmation before moving files to Trash. Quit apps using the files first.
Why is a folder still restricted after I allow access?

Folder-picker permission does not override every macOS privacy, App Sandbox, or file-permission restriction. If access is still denied after renewal, the app shows the reason and manual checks instead of repeatedly asking for the same permission.

Use “Open Files and Folders Settings” and “Show Location in Finder.” Do not change ownership or security settings of Apple or system folders arbitrarily. Contact the administrator of a work or school Mac. It is fine to skip some protected locations.

How can I restore cleaned files?

Select the files in Finder’s Trash and use “Put Back.” Connect an external disk if the files came from it. TidyHawk cannot guarantee automatic recovery after Trash is emptied or when macOS does not provide the restore action.

Why did available storage not increase by the cleanup size?

The completed size is measured immediately before files move to Trash, not an instant increase in free space. Files remain in Trash, and snapshots, shared data, and other apps writing files may affect available storage. Items that cannot be fully measured are excluded from the size total and counted separately.

Which files are cleaned while I am searching?

Only selected items visible in the search results are cleaned. Selections outside the search are excluded from this operation and become visible again when you clear the search. Check the count and size in the confirmation.

Does stopping cleanup stop it immediately?

Cleanup finishes the current file or model bundle before stopping ahead of the next item. Items already moved remain in Trash; unprocessed files stay in place. Cleanup History shows what happened and whether the operation was stopped.

Do “Needs Review” or “Unavailable” mean there is a security problem?

“Needs Review” asks for your review and does not confirm an infection. “Unavailable” means the app could not read the actual state. Use the reason, recommended actions, manual checks, and Apple help. An item disappearing in a later scan is marked as no longer observed, not automatically resolved.

Why can’t TidyHawk remove an app directly?

Ownership, locks, file permissions, and App Sandbox restrictions may require Finder authentication. An App Store receipt alone does not determine whether administrator authorization is needed. Check the app’s official uninstall method first and use Finder to inspect the location shown.

Stored data and privacy

Revoke folder access in app settings and remove trust on individual security items. The most recent 50 cleanup records are stored on this Mac.

Remove the cleanup history file manually

  1. Quit TidyHawk and back up records you want to keep.
  2. In Finder, choose Go › Go to Folder (⇧⌘G) and enter:
    ~/Library/Containers/kr.co.supracore.tidyhawk/Data/Library/Application Support/TidyHawk/
  3. To remove only cleanup history, move only cleanup-history.json to Trash. The folder may not exist if no history has been saved.

Other app settings may remain under Preferences or Application Support in the same app container. Email support for full reset guidance before removing data. Do not delete other apps’ containers or personal files.

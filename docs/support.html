암호·개인 파일·전체 보안 보고서는 보내지 마세요. 경로와 계정 이름이 담긴 화면은 가린 뒤 공유해 주세요.

자주 묻는 질문

처음에는 어떻게 사용하나요?
  1. 첫 화면에서 빠른 스캔 또는 원하는 정리 영역을 선택합니다.
  2. 폴더 선택 창에서 안내한 폴더의 접근을 허락합니다. 스캔 자체는 파일을 삭제하지 않습니다.
  3. 파일·경로·용량을 확인하고 필요한 항목만 선택합니다.
  4. 휴지통 이동 확인 창에서 대상을 다시 확인합니다. 실행 중인 앱은 먼저 종료하는 것이 좋습니다.
폴더를 허락했는데도 접근 제한이 나와요.

폴더 선택의 허락은 macOS 개인정보 보호·앱 샌드박스·파일 권한 제한을 모두 해제하지 않습니다. 재허락 뒤 같은 제한이 남으면 앱은 반복해서 허락을 요청하지 않고 제한 이유와 확인 방법을 안내합니다.

안내의 ‘파일 및 폴더 설정 열기’와 ‘Finder에서 위치 확인’을 사용하세요. Apple·시스템 폴더의 소유권이나 보안 설정을 임의로 변경하지 말고, 회사·학교 기기는 관리자에게 문의하세요. 일부 보호 영역은 건너뛰어도 됩니다.

정리한 파일은 어떻게 복원하나요?

Finder 휴지통에서 해당 파일을 선택한 뒤 ‘되돌려 놓기’를 사용하세요. 외장 디스크의 파일은 해당 디스크를 연결해야 확인할 수 있습니다. 휴지통을 비웠거나 macOS가 제공하는 복원 메뉴가 없는 경우 앱이 자동 복원을 보장하지 않습니다.

표시된 정리 용량만큼 여유 공간이 늘지 않았어요.

완료 용량은 이동 직전 측정한 파일의 디스크 사용량이며 즉시 증가한 여유 공간이 아닙니다. 파일은 휴지통에 남아 있고, 스냅샷·공유 데이터·다른 앱의 동시 쓰기 등에 따라 여유 공간 변화가 다를 수 있습니다. 용량을 완전히 측정하지 못한 항목은 합계에서 제외하고 개수를 표시합니다.

검색 중에는 어떤 파일이 정리되나요?

검색 결과에 보이는 선택 항목만 이번 정리 대상입니다. 검색 밖에 있던 선택은 이번 정리에서 제외되며, 검색어를 지우면 다시 보입니다. 확인 창의 개수와 용량을 확인하세요.

정리 중단을 누르면 바로 멈추나요?

현재 파일 또는 모델의 목록·데이터 묶음을 처리한 뒤 다음 항목부터 멈춥니다. 이미 옮긴 파일은 휴지통에 남고, 처리하지 않은 파일은 원래 위치에 남습니다. 정리 기록에서 중단 여부와 처리 결과를 확인할 수 있습니다.

확인 필요·확인 불가는 보안 문제가 있다는 뜻인가요?

‘확인 필요’는 사용자 확인이 필요한 설정이나 항목이며 감염 확정이 아닙니다. ‘확인 불가’는 앱에서 실제 상태를 읽지 못했다는 뜻입니다. 확인 이유·권장 조치·직접 확인 방법과 Apple 공식 도움말을 참고하세요. 재점검에서 사라진 항목도 해결됐다고 단정하지 않고 ‘미관찰’로 구분합니다.

앱을 직접 제거하지 못하는 이유는 무엇인가요?

앱 소유자·잠금·파일 권한·샌드박스 제한에 따라 Finder의 인증이 필요할 수 있습니다. App Store 영수증 유무만으로 관리자 권한이 필요하다고 판정하지 않습니다. 공식 제거 방법을 먼저 확인하고, 앱에서 안내하는 위치를 Finder에서 확인하세요.

저장 데이터와 개인정보

앱 설정에서 폴더 접근을 거둘 수 있으며, 보안 점검의 신뢰 항목은 해당 항목에서 취소할 수 있습니다. 최근 50회의 정리 기록은 이 Mac에 저장됩니다.

정리 기록 파일을 직접 삭제하려면

  1. TidyHawk을 종료하고 필요한 기록을 먼저 백업합니다.
  2. Finder에서 이동 › 폴더로 이동(⇧⌘G)을 열고 아래 위치를 입력합니다.
    ~/Library/Containers/kr.co.supracore.tidyhawk/Data/Library/Application Support/TidyHawk/
  3. 정리 기록만 지우려면 cleanup-history.json 파일만 휴지통으로 옮깁니다. 해당 폴더가 없다면 아직 기록이 저장되지 않았을 수 있습니다.

앱의 다른 저장 설정은 같은 앱 보관함의 Preferences·Application Support 등에 남을 수 있습니다. 전체 초기화가 필요하면 먼저 일반 문의로 방법을 확인하세요. 다른 앱의 보관함이나 개인 파일을 삭제하지 마세요.

무료·Pro 안내

출시 준비 중인 Pro 버전은 모든 스캔·결과 확인, 보안 점검과 해결 안내, 정리 기록 조회가 무료입니다. 시스템·개발자·AI 정리, 대용량 파일과 앱 제거 등 앱에서 실행하는 모든 휴지통 이동에는 Pro 일회성 인앱 구매가 필요합니다. 자동 갱신되는 구독이 아니며 Pro 화면에서 구매 복원을 지원합니다. 구매로 macOS 접근 제한이 해제되지는 않습니다.

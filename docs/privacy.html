개인정보 처리방침

시행일 · 최종 수정일: 2026년 10월 15일
운영자: TidyHawk 개발팀 (GitHub @Lucky301)

현재 버전의 TidyHawk에는 계정 가입, 광고·추적 SDK, 개발자 서버로의 자동 정보 전송 기능이 없습니다. 파일 정리와 보안 점검은 이 Mac 안에서 수행합니다.

1. 처리 목적과 정보 범위

사용자가 허락한 폴더의 파일 이름·경로·크기·시각, 설치 앱과 관련 파일, 실행 중인 프로그램, 시스템 보안 설정·계정·네트워크 정보를 기능 제공에 필요한 범위에서 기기 내에서 읽습니다. 접근할 수 없는 정보는 확인 불가로 구분합니다.

이러한 정보는 파일 정리 후보 표시, 실행 중인 항목 구분, 보안 상태 확인과 해결 안내에 사용합니다. 보안 점검은 악성코드 감염 확정이나 모든 위협 탐지를 보장하지 않습니다.

2. 이 Mac에 저장하는 정보

  • 사용자가 허락한 폴더의 접근 북마크와 재허락 이력
  • 사용자가 괜찮다고 지정한 보안 항목의 신뢰 기준
  • 최근 50회의 정리 날짜·영역·성공/실패 파일 경로·측정 용량·오류·중단 여부

이 정보는 앱의 로컬 보관함에 저장됩니다. 새 정리 기록이 50개를 넘으면 오래된 기록부터 대체합니다. 그 밖의 설정은 사용자가 해당 저장 데이터를 삭제할 때까지 보관합니다. 앱을 휴지통으로 옮기는 것만으로 보관함 데이터가 자동 삭제된다고 보장하지 않습니다.

3. 외부 전송과 제3자

이메일로 문의하면 회신을 위한 이메일 주소와 사용자가 보낸 내용을 고객지원 처리에 사용합니다. 문의 처리에 필요한 기간만 보관하며 불필요해진 정보는 삭제합니다. 법령상 보관 의무가 있는 경우 해당 의무를 따릅니다. 개인정보 관련 문의와 삭제 요청도 support@supracore.co.kr로 보낼 수 있습니다.

앱은 파일·스캔 결과·정리 기록을 개발자나 AI 서비스로 자동 전송하지 않습니다. 보안 보고서는 사용자가 직접 고른 위치에 저장합니다. 보고서에는 계정 이름·경로·설정 등이 포함될 수 있으므로 외부로 공유하기 전에 내용을 확인하세요. 사용자가 선택한 클라우드 저장 위치나 공유 서비스에는 해당 서비스의 정책이 적용됩니다.

Apple 공식 도움말을 열면 기본 브라우저에서 Apple 사이트에 접속합니다. 이 지원 사이트와 공개 문의 기능은 GitHub에서 호스팅하며, 방문·문의 과정에서 GitHub가 처리하는 정보에는 GitHub 개인정보 처리방침이 적용됩니다. 이 사이트에는 별도의 분석·광고 스크립트를 넣지 않습니다. 선택한 언어(한국어 또는 영어)만 브라우저의 로컬 저장소에 보관해 다음 방문에 적용합니다. 상단에서 언어를 바꾸거나 브라우저의 사이트 데이터를 지워 초기화할 수 있으며, 이 선택을 개발자에게 자동 전송하지 않습니다.

4. 사용자의 선택과 데이터 삭제

앱 설정에서 폴더 접근을 거둘 수 있고, 보안 점검 화면에서 항목별 신뢰를 취소할 수 있습니다. 앱 보관함 데이터의 삭제 방법은 고객지원의 저장 데이터 안내를 참고하세요. 권한을 거두는 것만으로 이미 생성된 정리 기록이 삭제되지는 않습니다.

정리한 파일은 휴지통에 남습니다. 복원은 Finder에서 수행하며 휴지통을 비우면 일반 복원 기능으로 되살릴 수 없습니다. 앱은 휴지통을 자동으로 비우지 않습니다.

5. 문의와 방침 변경

문의처: support@supracore.co.kr (TidyHawk 개발팀). 문의에는 필요한 최소 정보만 포함하고 암호·개인 파일·전체 보안 보고서를 보내지 마세요.

앱 기능이나 데이터 처리 방식이 바뀌면 이 방침과 최종 수정일을 갱신하고 필요한 경우 앱 안내를 업데이트합니다.
